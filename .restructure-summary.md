# Repository Layout

Implementation files are kept at the repository root to avoid nested
directories:

```text
.
├── hxyz
├── install.py
├── keybinding_config.txt
├── yazi.toml
├── README.md
└── ZELLIJ.md
```

Run `python3 install.py` from the root to install HXYZ. The installer loads
the executable, Yazi configuration, and Helix keybindings directly from this
directory.
