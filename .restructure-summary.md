## Installation Paths

### THXY (tmux variant)
```bash
cd tmux
python3 install.py
```
Installs:
- `~/.local/bin/thxy` and `~/.local/bin/th`
- `~/.config/thxy/`

### WHXY (WezTerm variant)
```bash
cd wezTerm
python3 install.py
```
Installs:
- `~/.local/bin/whxy` and `~/.local/bin/wh`
- `~/.config/whxy/`

## Keybindings

Both variants use identical keybindings:
- `space + m + f` - File picker
- `space + m + g` - LazyGit
- `space + m + o` - Copilot CLI
